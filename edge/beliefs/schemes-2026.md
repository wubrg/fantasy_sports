# 2026 scheme reference

Keyed to the belief-pack STAFF (`staff-2026.csv`): offense attaches to the **play-caller**, defense to
the **DC**. Web-sourced September 2026 (see per-team notes). **Look up once** — re-verify a team only on
a mid-season coaching change. Used to build the "Schematic matchup" section of each URPS game report.

**BUF, DET, and IND were added 2026-09-24** — a real gap in the original pass, discovered when three
separate Week 3 game reports each had to route around it with a same-session live lookup. Filled in
from that already-cited research rather than re-derived, same "look up once" discipline as every other
row.
